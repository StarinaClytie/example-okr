# Security policy

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/StarinaClytie/example-okr/security/advisories/new). Include the affected commit, application mode, steps to reproduce, expected and observed behavior, and a minimal example using fictional data.

Do not put credentials, private organization data, signed attachment URLs or exploit details in a public issue. Use an independent local test environment; do not test against deployments you do not own.

The current main branch is the maintained version. No response-time or support guarantee is offered. Local tests do not replace acceptance checks on your own hosted database, email and private object storage.
